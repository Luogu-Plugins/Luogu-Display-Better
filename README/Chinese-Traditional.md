## 專案簡介

Luogu Display Better 是一款面向 [洛谷](https://www.luogu.com.cn) 的輕量使用者腳本，透過視覺化設定面板實現頁面美化與個性化定制。它支援卡片模糊、透明度調節、圓角樣式、背景全螢幕、廣告遮蔽與自訂 CSS 注入。

## 功能亮點

- **卡片模糊**：為頁面卡片、浮層、彈窗和留言區加入玻璃模糊效果。
- **卡片透明度**：調整卡片背景透明度，打造更輕盈、更通透或更簡潔的視覺風格。
- **卡片圓角**：自訂卡片、文章區域等元素的圓角半徑。
- **圖片圓角**：統一為頁面中的圖片套用圓角樣式，提升視覺美感。
- **背景全螢幕**：將背景圖延伸至整個頁面，尤其適合使用首頁籤背景圖樣式的佈景主題。
- **廣告遮蔽**：隱藏洛谷部分頁面的廣告卡片，減少視覺干擾。
- **自訂 CSS**：直接輸入自訂樣式，即時注入頁面，快速打造個人化介面。

## 安裝指南

1. 安裝支援使用者腳本的瀏覽器擴充功能，例如 Tampermonkey、Violentmonkey 或 Greasemonkey。
2. 將 [`LuoguDisplayBetter.user.js`](https://github.com/Luogu-Plugins/Luogu-Display-Better/releases/download/latest/LuoguDisplayBetter.user.js) 檔案匯入使用者腳本管理員。
3. 開啟或重新整理 [洛谷](https://www.luogu.com.cn)，腳本會自動執行並生效。

## 使用說明

- 首次執行時，腳本會自動初始化預設設定。
- 頁面載入後，側邊欄會出現「美化外掛設定」按鈕，點擊即可開啟設定面板。
- 在設定面板中移動滑桿或切換開關，可即時預覽效果，設定立即生效。
- 在面板中輸入自訂 CSS，樣式會即時注入頁面。
- 按下 <kbd>Esc</kbd> 或點擊右上角紅色按鈕，可快速關閉設定面板。
