## 项目简介

Luogu Display Better 是一款面向 [洛谷](https://www.luogu.com.cn) 的轻量用户脚本，通过可视化设置面板实现页面美化与个性定制。它支持卡片模糊、透明度调节、圆角样式、背景全屏、广告屏蔽与自定义 CSS 注入。

## 功能亮点

- **卡片模糊**：为页面卡片、浮层、弹窗和评论区添加玻璃模糊效果。
- **卡片透明度**：调节卡片背景透明度，打造更轻盈、更通透或更简洁的视觉风格。
- **卡片圆角**：自定义卡片、文章区域等元素的圆角半径。
- **图片圆角**：统一为页面中的图片应用圆角样式，提升视觉美感。
- **背景全屏**：将背景图扩展至整个页面，尤其适合使用首选项卡背景图样式的主题页。
- **广告屏蔽**：隐藏洛谷部分页面的广告卡片，减少视觉干扰。
- **自定义 CSS**：直接输入自定义样式，实时注入页面，快速打造个性化界面。

## 安装指南

1. 安装支持用户脚本的浏览器扩展，例如 Tampermonkey、Violentmonkey 或 Greasemonkey。
2. 将 [`LuoguDisplayBetter.user.js`](https://github.com/Luogu-Plugins/Luogu-Display-Better/releases/download/latest/LuoguDisplayBetter.user.js) 文件导入用户脚本管理器。
3. 打开或刷新 [洛谷](https://www.luogu.com.cn)，脚本会自动运行并生效。

## 使用说明

- 首次运行时，脚本会自动初始化默认配置。
- 页面加载后，侧边栏会出现「美化插件设置」按钮，点击即可打开设置面板。
- 在设置面板中移动滑块或切换开关，可实时预览效果，设置立即生效。
- 在面板中输入自定义 CSS，样式会实时注入页面。
- 按 <kbd>Esc</kbd> 或点击右上角红色按钮，可快速关闭设置面板。
